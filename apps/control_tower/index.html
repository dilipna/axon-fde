The problem

A temperature alarm tells you the cargo is ruined. It doesn't tell you it's about to be.

Cargo with a narrow safe range

Many vaccines must stay between 2 and 8 °C for the whole journey. A few degrees too warm for too long and a truckload of medicine can't be used.

Alarms that fire too late

A standard alarm goes off only once the cargo has already left its safe range. By then there is nothing left to save.

Paperwork that disagrees

The company's order system and the signed shipping document often state different limits. If you trust the wrong one, a shipment at risk looks perfectly fine.

How it works

Four steps, and a person signs off before anything happens.

  1. 01

    Sense

    Reads the truck's sensors every minute: cargo temperature, outside heat, how hard the cooling unit is working, fault codes. It also reads the order system and the shipping papers.

  2. 02

    Predict

    Spots the trend, not just the current reading: a cooling unit slowly losing the fight shows up long before the cargo is too warm.

  3. 03

    Decide, with a human

    Prices every option, including doing nothing, and recommends the best. A fleet manager approves it. If conditions change after they sign, the approval is refused and must be renewed.

  4. 04

    Verify

    Checks afterwards whether the action actually worked, and reopens the case if it didn't. Every step is written to a record that can't be edited.

      Safety

      Built so the AI can't go rogue — and tested to prove it.

      It can't invent evidence

      A language model is never allowed to be the source of a sensor reading. The database itself rejects one.

      It can't act alone

      No action runs without a valid, unexpired approval that matches exactly what the approver saw.

      It can't change your records

      Read-only access to the company's order system, through six approved views, with every query checked before it runs.

      It can't rewrite history

      The audit log is append-only and hash-chained, so an edited or deleted entry is detectable.

      It admits what it doesn't know

      A missing reading stays missing and lowers confidence. It is never filled in with a guess.

      It shows its work

      Every number on this page traces to a stored run that anyone with the code can reproduce.
